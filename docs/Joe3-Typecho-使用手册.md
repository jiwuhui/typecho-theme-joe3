## 一、安装与升级

### 1.1 安装

1. 将 `joe3` 目录上传到 Typecho 站点的 `usr/themes/` 目录；
2. 控制台 → 外观 → 启用「Joe 3」；
3. 控制台 → 外观 → **设置外观**，配置主题（约 200 个设置项，全部有中文说明，默认值即开即用）；
4. 按[第三节](#三页面模板与独立页面)创建友链、留言板、归档、图库等独立页面。

### 1.2 升级

1. 用新版主题目录覆盖 `usr/themes/joe3`（**保留**原目录即可，设置保存在数据库中不会丢失）；
2. 主题版本号升位时（如 1.1.0），静态资源链接会自动变化，浏览器无需手动清缓存；
3. 升级后建议：设置页 → 备份区 → 「备份到数据库」留一条快照。

### 1.3 环境要求

- Typecho **1.3.0**（1.2 未验证，评论接口与 1.3 的安全机制有关）
- PHP 8.0+（建议 8.1）
- 无插件依赖，所有功能主题内置

## 二、后台设置分区详解

设置页顶部有「设置导航」可快速跳转到各分组。各分区重点项：

### 基本设置

| 设置项 | 说明 |
|---|---|
| 主题模式 | 用户模式（访客可切换浅色/深色，偏好存浏览器）/ 自动模式（按时间段自动切换）/ 固定浅色 / 固定深色 |
| 评论系统 | `default`（Typecho 原生评论，主题美化样式）或 `waline`（需另行部署 Waline 服务）|
| 主题色（浅色/暗黑）| 全站主题色，默认 `#fb6c28` 橙色。设置页内置**调色板**：点击预设色块或用取色器选色，自动填入输入框，两种模式分别配置 |
| 外部资源地址 | 把 `usr/themes/joe3/assets` 静态资源托管到 CDN 时填写，留空用本地 |

### 首页

- **顶部大图**：`启用顶部大图` 开关、大图图片地址、标题、一言开关、背景视频地址
- **轮播图**：`启用轮播图` 开关 + 轮播数据（见 5.2 节数据格式）
- **精品分类**：`展示精品分类` 开关
- **文章列表**：`开启文章缩略图`、`开启列表动画效果`、`是否开启自动加载`（滚动到底自动加载下一页，关闭则为分页按钮）

### 主题相关

- 浅色/深色模式背景图、背景图透明度
- 随机图：`启用随机图` + 随机图 API 地址（无封面文章的兜底封面，见 6.2 节）
- 页面加载条、离屏提示（切走标签页时标题变化）、模块缓入动画、返回顶部（含平滑滚动）

### 美化

- 页面加载条样式、离屏提示文案、模块缓入效果（全局）

### 导航

| 设置项 | 说明 |
|---|---|
| 导航菜单 | 自定义菜单，每行 `名称\|链接\|图标class`，留空则自动列出独立页面（详见第四节）|
| 导航条吸顶 | 滚动时导航固定顶部 |
| 100% 宽度 | 导航条内容通栏 |
| 展示博客 LOGO | 左上角 LOGO（logo 链接、圆角可配）|
| 开启菜单图标 | 菜单项前的图标（配合自定义菜单第三段）|
| 菜单图标悬浮动画 / 文字阴影 / 毛玻璃 | 视觉效果开关 |
| 导航栏登入按钮 | 导航右侧显示登录入口 |

### 博主信息

侧栏博主卡片：昵称、头像、签名、等级徽章、社交账号（浅色/深色背景时分别控制）。

### 代码块

代码块增强全家桶：代码标题、标题分隔线、mac 彩点、一键复制、行号、自动换行、代码折叠、自动折叠长代码块（阈值可调）、点击行内代码自动全选。

### 社交

社交图标配置（输出在博主卡片 / 页脚），支持自定义图标与链接。

### 侧边栏

- `启用全局侧边栏`（总开关，关闭后除文章页外全部无侧栏）
- 各页面独立控制：标签页 / 分类页 / 归档页 / 文章页 / 友链页 / 自定义页
- 侧栏位置：左侧 / 右侧

### 文章页

| 设置项 | 说明 |
|---|---|
| 文章 TOC 目录 | 桌面端文章目录（侧栏） |
| 移动端文章 TOC 目录 | 移动端左下角悬浮目录按钮 |
| TOC 目录默认展开层级 | 0~6，0 表示全部展开 |
| 文章浏览进度条 | 顶部阅读进度条 |
| 展示相关文章 | 文章底部相关推荐 |
| 文章编辑 | 登录用户显示后台编辑入口 |
| 文章评论 / 文章点赞 | 对应功能开关 |
| 文章分享 | 微信 / QQ / QQ 空间 / 微博 / 链接复制，可分别开关 |
| 文章可复制 | 关闭后正文禁复制 |
| 首行缩进 | 正文段落首行缩进 |
| 复制时追加版权信息 | 复制正文自动附加版权声明 |
| 展示相关设置 | 标题阴影、页面元数据、温馨提示（超期文章提示，天数可配）|
| 启用文章浏览进度条 | 顶部阅读进度 |

### 标签页 / 分类页 / 归档页

各列表页的标题、展示文章数、展示分类数据等微调。

### 友链 / 留言页

- 友链页标题、友链数据（格式见[第三节](#三页面模板与独立页面)）、友链默认 logo、随机前往
- 留言页展示来源：全部评论 / 仅留言板评论

### 图库

- **自动聚合文章图片**：开启后图库自动收录文章正文中的图片（详见第七节）
- **聚合分组名**：自动收录图片的分组名，默认「文章」

### 广告

开启广告后可配置：侧栏广告（图片/代码）、文章底部广告，多行数据格式。

### 页脚

- 启用页脚 / 100% 宽度
- 博客运行时间展示（起始日可配）、ICP 备案号、公网安备、PowerBy
- RSS、站点地图、访问量统计（不蒜子）入口开关

### 自定义

- 自定义 CSS：输出到全站 `<head>`（可覆盖插件/主题样式）
- 自定义 JS（head）：输出到 `<head>` 末尾
- 自定义页脚统计代码等

### 其他

- 控制台输出页面加载耗时 / 主题信息
- 调试模式（vconsole 移动端调试按钮）
- RIP 模式（全站黑白化，用于哀悼日）
- 绿色模式（隐藏打赏、最新评论等模块）
- 检查百度收录情况（需配置百度推送 Token）

## 三、页面模板与独立页面

主题自带 6 个自定义模板，通过「独立页面」使用。

### 3.1 创建步骤

1. 控制台 → **管理 → 独立页面 → 撰写**；
2. 填写标题（即页面与菜单显示名）；
3. 正文可留空（各页面数据在主题设置或自定义字段中维护）；
4. 展开「高级选项」→「**自定义模板**」选择对应模板；
5. 发布后页面自动出现在导航菜单（未使用自定义导航菜单时）。

### 3.2 模板一览

| 模板下拉名 | 页面用途 | 数据来源 |
|---|---|---|
| 友情链接 | 友链展示 | 主题设置 → 友链 → 友链数据 |
| 留言板 | 访客留言（评论区）| 站点评论 |
| 文章归档 | 按月时间轴 + 分类统计 | 自动生成 |
| 图库/相册 | 图片瀑布流 | 页面自定义字段 `photos` + 自动聚合 |
| 分类列表页 | 全部分类导航 | 自动生成 |
| 标签列表页 | 全部标签汇总 | 自动生成 |

### 3.3 友链数据格式

主题设置 → 友链 → 「友链数据」，每行一条，`[]` 行为分组：

```
[朋友们]
张三的博客|https://blog.example.com/zhang||前端与生活
李四的笔记|https://blog.example.com/li|https://example.com/logo.png|记录学习
[技术站点]
技术小站|https://tech.example.com||分享技术
```

字段顺序：`名称|网址|logo|描述`，logo 与描述可留空。

### 3.4 隐藏某个页面

不想让某独立页面出现在导航：编辑该页面 → 高级选项 → 勾选「隐藏页面」（页面本身仍可通过 URL 访问）。

## 四、顶部导航菜单

### 4.1 生成规则

1. 主题设置「导航菜单」**填写了内容** → 完全按自定义内容显示；
2. **留空（默认）** → 显示「首页」+ 全部独立页面（隐藏的除外）。

### 4.2 自定义菜单格式

每行一条：`名称|链接|图标class`（图标可留空）：

```
首页|/|jiewen joe-icon-shouye
友链|/links.html|jiewen joe-icon-zuzhijiagou
留言板|/leaving.html|
日志|https://blog.example.com/|
```

- 图标 class 基于主题内置 FontAwesome 兼容层（`assets/css/joe-icons.css`），也可使用 `fa fa-xxx` 格式
- 需同时开启「导航 → 开启菜单图标」
- 当前页菜单项自动高亮

### 4.3 相关说明

- 「为什么我的菜单只有首页和关于？」——新站只有 Typecho 自带的「关于」独立页面，按 3.1 节创建更多页面即可
- 导航条吸顶、100% 宽度、毛玻璃等外观设置在「导航」分区

## 五、首页功能

### 5.1 顶部大图

开启「主题相关 → 启用顶部大图」后，首页首屏显示全屏大图：

- 大图图片地址、主标题（打字机动画）、一言（hitokoto）、背景视频可配置
- **沉浸式导航**（1.1.0 新增）：页面在顶部时导航透明覆盖在大图上（白色菜单文字，顶栏搜索/调色板/主题切换图标同步变白），向下滚动超过约 120px 后，导航以白底（深色模式下深底）滑入吸顶。仅桌面端（≥768px）生效
- 底部波浪过渡连接正文，点击向下箭头可滚动到内容区

### 5.2 轮播图

开启「首页 → 启用轮播图」并填写「轮播数据」（每行一条，三种写法）：

```
10                              ← 文章 cid：轮播该文章（标题/摘要/封面自动读取）
custom|自定义标题|描述|https://example.com|https://example.com/cover.jpg   ← 完全自定义
hot|3                           ← 自动轮播热门文章前 3 篇
```

可配置：循环播放、手动控制、左右切换按钮、分页器、自动切换、切换速度与停留时长。

### 5.3 顶栏工具与主题色调色板（1.1.0 新增）

导航右侧、与登录按钮同一行，按顺序排列三个图标按钮（风格统一，图标颜色实时跟随主题色）：

```
[🔍 搜索] [🎨 调色板] [🌙 主题切换] [登录/头像]
```

- **搜索**：打开搜索浮层，输入关键字后跳转搜索结果
- **调色板**：打开主题色调色板面板（见下）
- **主题切换**：一键切换浅色/深色模式（仅「用户模式」显示；「自动模式」下按时间自动切换）
- 移动端（<768px）隐藏这三个按钮，深浅切换仍可在文章页悬浮条使用（悬浮条按钮）
- 首页大图沉浸态下图标自动变白

**主题色调色板面板**：

1. **色相滑块**：拖动即时预览全站变色（按钮、菜单、高亮同步），滑块自动定位到当前色相
2. **预设色块**：12 个常用色一键切换
3. **恢复默认**：清除访客自定义，回到博主在后台设置的主题色
4. **配色记忆**：按深色/浅色模式**分别**保存在访客浏览器（localStorage），刷新、换页、切换深浅模式都自动应用

> 注意区分：前台调色板是**访客个性化**（只影响自己的浏览器）；博主想让全站换色请使用后台「主题色」设置的调色板（第二节）。两者互不干扰，访客未自定义时显示博主设置的全站色。

### 5.4 文章列表

- 缩略图优先级见 6.2 节
- 列表动画、精品分类展示可开关
- 自动加载：滚动到底部自动请求下一页（需同时开启「首页 → 是否开启自动加载」与「列表 ajax」相关项）；文章数不足一页时不出现分页

## 六、文章写作与文章页功能

### 6.1 文章自定义字段

编辑文章 → 高级选项 → 自定义字段：

| 字段 | 说明 |
|---|---|
| `thumb` / `cover` | 文章封面地址（两名字任选）|
| `img_align` | 正文图片对齐：`left` / `center` / `right` |
| `enable_copy` | `false` 禁止本篇复制 |
| `enable_toc` | `false` 关闭本篇目录 |
| `toc_depth` | 本篇目录展开层级（数字）|
| `views` / `likes` | 浏览量 / 点赞数（主题自动维护，一般无需手填）|

### 6.2 封面（缩略图）优先级

```
thumb/cover 字段 → 正文第一张图 → 随机图 API（开启时）→ 默认缩略图（post_thumbnail 设置）
```

**随机图 API 说明**：

- 「主题相关 → 启用随机图」开启后，无封面的文章使用「随机图 API 地址」兜底
- **随机图 API 地址（或默认缩略图位置填写的同一 API）会被每篇文章、每次页面加载追加唯一参数**，保证列表中每篇文章、每次刷新都随机出不同的图，不会因浏览器缓存显示同一张（1.1.0 修复）
- 手动在 thumb/cover 字段中填写的 API 地址同样会被唯一化处理；真实图片地址不受影响

### 6.3 文章目录（TOC）

- 正文中的 h1~h6 标题自动生成目录（桌面显示在侧栏「文章目录」卡片，移动端在左下角悬浮按钮）
- 全局开关与展开层级在「文章页」分区；单篇可用自定义字段覆盖
- 点击目录项平滑滚动到对应标题，滚动时高亮当前位置
- 「原始内容」模式（`use_raw_content` 字段）的文章不支持 TOC 解析

### 6.4 点赞 / 浏览 / 评论

- **点赞**：文章页左下角悬浮条与点赞按钮，点击后即时显示服务端最新计数；同一访客对同一篇文章仅计一次（刷新/换浏览器后可再赞）
- **浏览量**：访问文章页自动 +1
- **评论**：见第九节

### 6.5 代码块增强

文章中的代码块（Prism 高亮）支持：语言标题、分隔线、mac 彩点、一键复制、行号、自动换行、折叠、长代码自动折叠。全部在「代码块」分区开关。

### 6.6 其他

- 图片点击打开灯箱大图（fancybox）
- 复制保护：关闭「文章可复制」或文章字段 `enable_copy=false` 后正文禁复制；开启「复制时追加版权信息」则复制内容自动附带版权声明
- 文章分享：生成微信二维码、QQ/空间/微博分享链接、复制链接（模板可自定义）
- 打赏：开启后显示打赏二维码（图片地址在打赏设置中配置）

## 七、图库使用

### 7.1 创建图库页面

1. 管理 → 独立页面 → 撰写，标题如「图库」；
2. 自定义模板选择「**图库/相册**」；
3. 发布，通过导航或 `/photos.html` 访问。

### 7.2 手动添加图片

编辑图库页面 → 高级选项 → 自定义字段，添加字段：

- 字段名称：`photos`（小写，精确匹配）
- 字段值（每行一条）：`图片地址|描述`

分组语法：单独一行 `[分组名]`，其后的图片归入该分组：

```
[风景]
https://example.com/1.jpg|山间晨雾
https://example.com/2.jpg|湖畔黄昏
[城市]
https://example.com/3.jpg|夜景霓虹
```

- 描述可留空（`地址|`），会作为图片的 alt 文字
- 不写 `[分组名]` 行时，所有图片归入「全部」
- 图片地址支持站内附件或任何外链
- 更新页面后刷新图库页即生效
- 分组多于一个时，页面顶部出现筛选按钮

### 7.3 自动聚合文章图片（1.1.0 新增）

设置 → 图库 → 「**自动聚合文章图片**」开启后（默认开启）：

- 图库自动扫描**全部已发布文章的正文**，收录其中图片（Markdown `![]()` 与 HTML `<img>` 均支持）
- 自动收录的图片归入「**聚合分组名**」分组（默认「文章」），按文章发布时间倒序
- 与手动配置的图片**按地址去重**，手动配置优先
- 加密文章、草稿不参与聚合；聚合出错不影响手动数据展示

典型工作流：写文章时插入图片 → 发布 → 打开图库页，图片已自动出现在「文章」分组。

### 7.4 图库页功能

- **分组筛选**：分组多于一个时，顶部出现筛选按钮（全部 / 各分组名），点击即时切换
- **灯箱大图**：点击任意图片打开灯箱（fancybox）浏览
- **懒加载**：滚动到可视区域才加载图片，首屏加载快
- **瀑布布局**：masonry 瀑布流自适应排列

## 十、设置备份与恢复

设置页顶部「备份 / 恢复」区提供三种方式：

### 10.1 备份到数据库（推荐）

- 点击「**备份到数据库**」，当前全部设置（含各分区）存入站点数据库

### 10.3 恢复生效方式

## 十一、常见问题 FAQ

**Q1：为什么我的导航只有「首页」和「关于」？**
新站只有一个自带独立页面。按第三节创建友链、留言板等页面后自动出现；或用自定义菜单。

**Q2：图库页面是空的？**
依次检查：① 页面的自定义模板是否选了「图库/相册」；② 自定义字段名是否精确为 `photos`（小写，字段类型 str）；③ 若依赖自动聚合，检查主题设置「图库」分区的开关是否开启、文章正文里是否有可外链的图片。

**Q3：图库手动配置的图片和自动聚合的重复了？**
不会——主题按图片地址去重，手动配置优先。

**Q4：文章列表所有封面是同一张图？**
检查「主题相关 → 随机图 API」与「文章缩略图」设置：使用随机图 API 时 1.1.0+ 会自动参数化；若使用的是固定图片地址则必然相同，请改用随机图 API。

**Q5：评论提交后没有反应 / 评论丢失？**
1.1.0 已修复主题未输出反垃圾令牌的问题。若仍失败，检查：设置 → 评论 → 「开启反垃圾保护」是否勾选（必须开启）；是否触发了评论间隔限制。

**Q6：切换页面时闪白？**
1.1.0 已修复（深色模式初始化提前到页面头部）。若仍出现，确认上传的 header.php 是最新版。

**Q7：移动端目录按钮不出现？**
移动端目录依赖浏览器 UA 判断（真机生效），桌面浏览器缩窄窗口不会触发；桌面端目录显示在文章侧栏。

**Q8：怎么改主题色？**
设置 → 基本 → 主题色（浅色）/ 主题色（暗黑），分别填写色值。

**Q9：如何全站临时置灰？**
设置 → 其他 → RIP 模式。

**Q10：链接跳转想新窗口打开 / 站内跳转？**
设置 → 基本 → link_behavior 相关项。

**Q11：升级主题后设置会丢吗？**
不会，设置保存在数据库；升级后建议手动留一条数据库备份。

**Q12：前台调色板改的颜色和后台「主题色」是什么关系？**
前台调色板是访客个性化（存访客浏览器，只影响自己）；后台「主题色」是全站默认色。访客未自定义或点了「恢复默认」时，显示后台设置的全站色。

**Q13：导航上的搜索/调色板/主题切换按钮想换位置或隐藏？**
三个按钮输出在 `lib/navbar.php` 的 `.joe_header__above-search` 内，顺序：搜索 → 调色板 → 主题切换 → 登录。调色板按钮可整块删除；主题切换受「主题模式=用户模式」控制（其他模式自动消失）。移动端（<768px）默认隐藏，可在样式块中调整。

## 本地测试环境说明

这套本地环境完全是用「PHP 官方便携包 + Typecho 自带的内置服务器」搭的，没有任何额外的 Web 服务器软件。分四部分说明：

### 1. 便携 PHP（`Halo\php81\`）

从 windows.php.net 下载的 PHP 8.1.31 免安装 zip，解压即用。唯一改动是 `site\php.ini`（复制自 php.ini-development）里启用了几个扩展：

```ini
extension_dir = "ext"
extension=pdo_sqlite
extension=sqlite3
extension=mbstring
extension=openssl  curl  fileinfo  gd
```

Typecho 跑 SQLite 依赖的就是 `pdo_sqlite`。

### 2. 站点目录（`Halo\site\`）

一份完整的 Typecho 1.3.0 源码，主题装在 `site\usr\themes\joe3`，数据库是 `site\usr\joe3.db`（SQLite 单文件）。安装没有走网页向导，而是用 Typecho 内置的 **CLI 安装器**——设置环境变量后一条命令完成建表、写配置、建管理员：

```bat
set TYPECHO_DB_ADAPTER=Pdo_SQLite
set TYPECHO_DB_FILE=D:\...\site\usr\joe3.db
set TYPECHO_DB_NEXT=keep
set TYPECHO_USER_NAME=admin
php install.php
```

### 3. 服务器本体（`php -S` + router.php）

启动命令只有一行：

```bat
php81\php.exe -c site\php.ini -S 127.0.0.1:8093 site\router.php
```

`-S` 是 PHP 内置服务器（单进程、仅限本地测试）。它本身不懂 Typecho 的伪静态路由，所以靠 `site\router.php` 做“路由分发器”，每个请求先经过它，逻辑就三条：

1. **真实存在的静态文件**（CSS/JS/图片）→ `return false` 交还给内置服务器直接吐出
2. **真实存在的 PHP 文件**（`/admin/**`、`install.php`）→ `chdir` 到该目录后原生执行——这就是上次后台 404 修复的点
3. **其余路径** → 设置 `$_SERVER['PATH_INFO']` 后 `require index.php`，让 Typecho 自己的路由器接手（比如 `/index.php/archives/3/` 解析出文章 cid）

这就是为什么同一个端口既能跑后台、又能跑前台伪静态、还能直接吐主题资源。

### 4. 主题同步（`Halo\sync-theme.ps1`）

主题的“源码”在 `Halo\joe3`（开发目录），站点里跑的是 `site\usr\themes\joe3`。每次改完主题我用一条 robocopy 镜像同步：

```powershell
robocopy joe3 site\usr\themes\joe3 /MIR
```

PHP 不需要重启——每次请求都重新读盘，改完同步刷新页面即生效。

### 与正式部署的差别

这套东西**只用于本地开发测试**：内置服务器是单进程的，没有并发能力和安全加固。上生产时应该是 Nginx/Apache + PHP-FPM（或 phpstudy 这类集成环境），router.php 那段逻辑对应换成 Nginx 的 `try_files` + PATH_INFO 规则即可，主题本身不依赖这些。
